suas dúvidas.

Nunca programei. Consigo acompanhar?

Sim. O curso é feito para quem não é de tecnologia: você explica em português o que precisa, confere o plano e aprova o resultado. Se você usa e-mail e navegador, já consegue acompanhar.

Preciso instalar alguma coisa?

Não. Tudo é feito no navegador, com o Claude Code na web e uma conta gratuita no GitHub para guardar os seus projetos.

Preciso pagar o Claude?

Sim. O Claude Code exige uma conta do Claude em um plano pago. Na aula "Planos e custos" você vê as opções e qual delas atende ao curso. O GitHub usado no curso é gratuito.

Quanto tempo preciso por dia?

As aulas têm de 1 a 3 minutos. Dá para assistir uma aula, repetir o pedido com a pasta do aluno e ver o resultado no mesmo dia.

Posso usar com dados da minha empresa?

O último módulo trata disso: o que nunca enviar para a IA, os cuidados com a LGPD e os sinais de que é hora de chamar a TI.
