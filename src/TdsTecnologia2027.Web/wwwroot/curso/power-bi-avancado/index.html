suas dúvidas.

Para quem é este curso?

Para quem já usa o Power BI no dia a dia (importa dados, cria visuais e medidas simples) e quer dominar os recursos avançados. Se você está começando, faça antes o Power BI Essencial.

Qual ferramenta vou usar?

O Power BI Desktop, gratuito para Windows, em uma versão recente (alguns recursos, como funções DAX e calendários, são novos). Na aula de IA, usamos também o Claude Desktop.

Preciso de licença Pro ou Premium?

Não. Todas as aulas são feitas no Power BI Desktop. Onde algum recurso depende do Serviço do Power BI, como a publicação da RLS ou o Copilot, a aula explica o que é preciso.

Tem material para acompanhar?

Sim. Você baixa a base de dados, o arquivo de partida, o caderno de atividades e todos os códigos DAX prontos para copiar e colar.
