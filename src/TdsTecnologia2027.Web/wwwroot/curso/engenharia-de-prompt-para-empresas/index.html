Não. O curso começa explicando como a IA funciona e onde ela erra, em linguagem simples. Se você já usa, vai sair com um método para ter respostas melhores na primeira tentativa.

Preciso pagar o ChatGPT, o Claude, o Gemini ou o Copilot?

Não. As versões gratuitas atendem ao curso. Quando um recurso depende de plano pago ou corporativo, isso aparece sinalizado na aula.

O curso é só sobre uma ferramenta?

Não. O método CRIAR vale para qualquer assistente de IA. Você vê o que cada ferramenta faz melhor e quando usar cada uma.

Um módulo inteiro trata disso: o que nunca colar na IA, como anonimizar dados, a LGPD e a política de uso de IA da empresa, com um modelo pronto para adaptar.
